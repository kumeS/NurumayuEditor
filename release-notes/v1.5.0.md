## 1. このアップデートの概要

- QA 実行 `20261003-computer-use-v1` で報告された不具合 9 件（P2 が 5 件、P3 が 4 件）をすべて修正した。
- 中心は「未保存」の判定の統一である。タイトル・Markdown プレビュー・発表者ノートの編集を Undo で保存時の状態に戻しても、「未保存」が消えなかった。一方で変更の表示は「保存時と同じ内容」となり、両者が矛盾していた。判定を 1 つにまとめ、フッター・タブの印・変更の表示が一致するようにした（BUG-001・005・007）。空の Markdown タブでの 2 つの特殊なケースは KI-49・KI-50 に記載した。
- 次の不具合も修正した。
  - 検索と置換の Undo 後の表示（BUG-002）
  - スライドのタブの読み上げ（BUG-003）
  - 行へ移動の入力チェック（BUG-004）
  - レビューパネルの Esc（BUG-006）
  - ヘルプの書き出し形式（BUG-008）
  - 発表を終えた後のスライドの位置（BUG-009）
- 修正の後にコード全体のレビューを行い、見つかった問題も直した。主なものは次のとおり。
  - Markdown プレビューの段落に入力中に検索バーの「置換」を押すと、入力した文字が消える（以前からあったデータ消失）
  - 発表モードを開いても、背面の本文に文字が入力される
  - 保存されていない変更が「保存済み」と表示される特殊なケース
- 不具合の修正が中心だが、操作の変更を含むため、マイナーバージョンを上げて 1.5.0 とした。主な変更は、Esc でパネルを閉じる、ノート欄の ⌘Z、行へ移動の入力チェックである。変更点は 2.3 節にまとめた。
- **実機での動作確認はまだ行っていない。** 自動テストはすべて成功している（5 章）。分かっている問題は 3 章（Known Issues）、未実装の機能は 4 章（Future Release）にすべて記載した。

### 2.2 不具合の修正

**変更状態と Undo**

- タイトル欄で ⌘Z を押して保存時のタイトルに戻しても、「未保存」のままだった。保存時と同じ内容に戻ると「保存済み」になる（BUG-001）。
  - Markdown ファイルでは、見出し行の書き方や空行も保存時のバイト列のまま戻す。
  - タイトルを編集する前に Markdown ソースで行った変更は、巻き戻さない。
  - タイトルの編集が文書の Undo 履歴に入らない制限（KI-06）は変わらない。
- Markdown プレビューの「＋ 段落を追加」で入力し、⌘Z で取り消しても「未保存」のままだった。Markdown やスライドに切り替えた後の編集を Undo で戻した場合も、保存済みに戻るようにした（BUG-005）。
- 発表者ノートの入力が、欄からフォーカスが外れるまで文書に反映されていなかった（BUG-007）。そのため次の問題があった。
  - 入力中も「保存済み」のままで、「元に戻す」も使えなかった。
  - タブの閉じるボタンの 1 回目が効かなかった。
  - Undo の後に、欄の表示と文書が食い違った。
  - モードを切り替えると、ノートが消えたように見えた。

  入力と同時に文書へ反映するようにした。続けて入力した分は 1 回の Undo でまとめて戻り、日本語変換の途中で区切られることはない。
- 切り離したスライドの箇条書き欄にも、発表者ノートと同じ問題があった。入力と同時に反映するようにした。入力途中の空行や末尾の空白は消えない。
- フッターの「未保存」と変更の表示が、別々の基準で判定されていた。1 つの判定にまとめた。保存時と同じ文章に打ち直した場合も、保存済みに戻る。
- 変更があるのに「保存済み」と表示され、閉じるときに確認が出ないケースがあった。次の 3 つで、いずれも Markdown 表示で起きる。
  - 見出しだけの `.md` で、全選択して削除した場合
  - 空の `.md` に見出しを入力した場合
  - エディタ表示で保存した `.md` の内容を削除した場合
- AI で書き換えた段落を元の版に戻しただけの文書も、「未保存」として扱う（`.aix` に保存される版の履歴を守るため）。
- 保存の書き込み中に入力した文字が、保存前の入力と同じ Undo のまとまりになり、Undo が保存時の状態で止まらないことがあった。保存を始めた時点で区切るようにした（エディタとスライド）。
- 関係の分析の後に入力した文字が分析と同じ Undo のまとまりになり、1 回の Undo で両方が消えていた。
- 切り離したスライドの箇条書きとノートで、空白など文書に保存されない入力が Undo のまとまりの時間を延ばさず、ゆっくり入力すると単語ごとに区切られていた。
- Markdown ソースで、置換や「元に戻す」で文書が変わった直後にソース内で ⌘Z を押すと、取り消したはずの変更がもう一度適用されることがあった。ソースの外からの変更は、ソース側の Undo 履歴に残さないようにした。
- 改行コードが混在した Markdown で「元に戻す」を使うと、余分な Undo が記録され、やり直しができなくなっていた。

**検索と行へ移動**

- Markdown ソースで「すべて置換」の後に ⌘Z / ⇧⌘Z を押すと、検索バーの件数とボタンが更新されず、「N 件を置換しました」が残り続けていた。どの方法で本文が変わっても、現在の本文から検索結果を計算し直す。エディタでも同じ（BUG-002）。
- 「行へ移動」が 0、行数を超える値、負の数、小数を受け付け、黙って最寄りの行へ移動していた（BUG-004）。
- Markdown プレビューの段落に入力中に、検索バーの「置換」「すべて置換」をクリックすると、入力した文字が消えていた。
- 置き換えても何も変わらない「すべて置換」（すでに置換後の文字になっている場合など）で、「N 件を置換しました」と表示され、続く ⌘Z が無関係の編集を取り消していた。何も変わらないときは「変更箇所はありません」と表示し、Undo の対象にしない。
- 「すべて置換」の後に「大文字と小文字を区別」「単語単位」を切り替えても、「N 件を置換しました」が残っていた。
- 文書の Undo の後に、選択中の一致の番号（「1 / 3」）が「3 件」と表示されていた。
- 状態表示の文字数が変わると「↑」「↓」ボタンの位置がずれ、クリックが外れることがあった。

**スライドと発表**

- スライドの「スライドを編集」「スライドをプレビュー」タブが、VoiceOver などで両方とも選択中と伝えられることがあった。表示中のタブだけが選択中と伝わるようにした（BUG-003）。
- 発表を終えると、発表前に選んでいたスライドに戻っていた（BUG-009）。
  - 終了時に表示していたスライドを選択し、次の発表もそこから始まる。
  - Esc、右上の ×、下部の「Escで終了」のどれで終えても同じ。
  - この選択の変更で未保存にはならない。
  - 編集表示では、終了後にそのスライドの段落へカーソルが戻る。
- コマンドパレットから発表を始めると、フォーカスが背面の本文に残り、キー入力で文書が書き換わっていた。発表画面を開いたときにフォーカスが移るようにした。
- スライドの図の案内文が「まだ .pptx に書き出されません」となっていたが、実際には画像レイアウトのスライドでは書き出されていた。実際の動作に合わせた文言にした。

**キーボード**

- レビューパネルを Esc で閉じられなかった（BUG-006）。ほかのパネルとポップオーバーも Esc で閉じられるようにした（v1.4.0 の KI-35 を含む）。
- レビューパネルに送信していないコメントがあるとき、Esc でパネルが閉じてコメントが消えることがあった。コメントがあるときは閉じずに、コメント欄へフォーカスを移す。
- 次のものを開いたまま Esc を押すと、開いているパネルや別のメニューまで一緒に閉じることがあった。1 回の Esc で閉じるのは 1 つだけにした。
  - Markdown プレビューの背景色メニュー
  - リンクのポップオーバー
  - ツールバーのメニュー
  - 検索バー
- 右下に開くパネル（レビュー基準・個人ライブラリ・引用）が重なり、見えていない方を Esc で閉じることがあった。同時に開くのは 1 つだけにした。
- 数式（TeX）の編集ポップアップで、入力欄にカーソルがあると Esc で閉じられなかった。日本語変換を Esc で取り消したときは閉じない。
- リンクのポップオーバーが、日本語変換を取り消す Esc でも閉じていた。

**ヘルプ**

- ヘルプ「6. 保存と書き出し」の書き出し形式に、PPTX が載っていなかった（BUG-008）。

### 2.3 動作の変更（アップデート時の注意）

| 変更 | 以前 | このバージョン |
|---|---|---|
| 発表者ノート・切り離したスライドの箇条書きでの ⌘Z | 欄の中の Undo | 文書の Undo。続けて入力した分は 1 回でまとめて戻る。メニューの「元に戻す」と同じ |
| Esc | ダイアログ、検索バー、ツールバーのメニューを閉じる | 加えて、パネルとポップオーバーを閉じる（2.1 節）。本文の段落にカーソルがあるときも閉じる。Markdown ソース・タイトル欄・ダイアログ・検索バー・パネル内の入力欄では、パネルを閉じずにその欄の操作として扱う |
| 行へ移動 | 範囲外の値は最寄りの行へ移動 | 1〜総行数の整数以外では移動しない |
| 空白だけの変更 | 変更差分パネルでは変更として数えない | 変更として数える（未保存になり、変更差分パネルに出る） |
| 保存時と同じ内容に戻した場合 | 未保存のままのことがあった | 保存済みに戻る |
| 発表の終了 | 発表前のスライドが選択されたまま | 終了時のスライドが選択される |
| Markdown ソースの ⌘Z（ソースの外で文書が変わった直後） | ソースの外の変更を取り消す（取り消したはずの置換が戻ることがあった） | 何もしない。ソースに入力すると、その入力から再び ⌘Z が使える。「編集 → 元に戻す」は常に使える |
| 右下のパネル（レビュー基準・個人ライブラリ・引用） | 複数を同時に開ける | 1 つを開くと、ほかの 2 つは閉じる |
| 何も変わらない「すべて置換」 | 「N 件を置換しました」 | 「変更箇所はありません」。Undo の対象にならない |
| 閉じるボタンのツールチップ | 「パネルを閉じる」など | 「パネルを閉じる (Esc)」「閉じる (Esc)」 |
