NurumayuEditor v1.4.0 shipped on 2 October 2026, about three months after v1.3.0. It is the first numbered release that includes everything built since July, and the main theme is trust: the editor no longer changes your data without being asked. It also fixes 18 of the 21 defects found in QA.

What is NurumayuEditor?

A local-first Markdown and slide editor built on chunks.

One file, two faces

The same chunks are your document and your deck.

AI per chunk

Translate, proofread, expand, diagram, in context.

SECURITY

A scratchpad for weekly progress, not a finishing tool

NurumayuEditor treats a document as an ordered list of chunks, like notebook cells for writing. That list is projected two ways: a document you edit and a deck you present, with no export step in between. Each chunk is also the unit for AI actions (translate, proofread, expand, summarize, diagram, illustrate), which read the surrounding context and can draw on a personal library kept entirely on the device. API keys live in the OS keychain and all network calls happen in Rust. It is meant for rough weekly progress; final polish still happens in your usual apps.

Source: release notes v1.4.0 · §2.1, §2.4

Six headline features. Find and Replace works in the Editor and Markdown source, including Japanese, with Go to Line and a one-step undo of Replace All. The model picker loads the OpenRouter list with search, a free-only filter and prices. PDF export now writes directly. Saving gained Save As on ⇧⌘S and a three-way prompt for unsaved changes, and the last tab can be closed. The AI operations log records only identifiers, never document text or keys. Slide commands are all in the command palette. Also shipping under a version number for the first time: the Markdown workspace, Presentation mode, ghost-text completion, the on-device personal library, citations, the CLI and the read-only MCP server.

Source: release notes v1.4.0 · §2.2, §2.3

Left: the fixes that matter most, all about not touching data the user didn't ask to change. An AI result is applied only when the tab, the loaded document and the sent text all still match (BUG-001). Switching between Markdown, Editor and Slides no longer marks the document unsaved or rewrites its source; an unedited round trip is byte-for-byte identical (BUG-019). Undo works per field, Esc closes dialogs, and focus can no longer reach buttons behind a dialog. Right: changes users will notice on upgrade. ⇧⌘S used to overwrite; exports to a path with no extension are now refused; and automation scripts that find the per-paragraph AI button by name need updating, since its label changed.
