## 1. Overview of this update

- Fixed 18 of the 21 defects reported in QA run `20260927-computer-use-v1`. These include the defects that changed data without the user asking: an AI result landing in a different document, and switching modes rewriting the Markdown.
- Added new features: Find and Replace, choosing a model from the OpenRouter model list, and direct PDF export.
- Translated the English text that was left in the Japanese UI.
- Features built after v1.3.0 that had never shipped under a version number (the Markdown workspace and others) are part of this version (section 2.4).
- **The new build has not yet been checked in the running app.** All automated tests pass (section 5). Every known problem is listed in section 3 (Known Issues), and every feature not yet built is listed in section 4 (Future Release).

## 2. What's updated

### 2.1 New features

| Feature | Detail |
|---|---|
| Find and Replace | Find, Replace, Find Next, Find Previous and Go to Line work in the Editor and in Markdown source. They are available from the Edit menu, from ⌘F / ⌥⌘F / ⌘G / ⇧⌘G / ⌘L, and from the command palette. Replace All can be undone in one step. Japanese text can be searched |
| OpenRouter model list | Settings can load the current model list. You can search it, show free models only, check prices, and pick a text model and an image-generation model. A saved model that is not in the list is marked |
| Direct PDF export | **Export as PDF** opens a save dialog and writes the file directly. The status bar shows how many images and diagrams could not be included |
| Save As entry points | **Save As…** was added to the Save button's menu and to the command palette. ⇧⌘S opens it |
| Three choices for unsaved changes | When you close a tab or quit, you can choose **Save / Don't Save / Cancel** |
| Closing the last tab | The last remaining tab can be closed. Closing it leaves a new empty document. **Close Tab** was added to the File menu |
| Recent AI operations log | The network panel shows when each AI operation started, was applied or was discarded, with the reason for each discard. It records identifiers only, never document text or API keys. The log can be copied |
| Build identifier | The bottom of the Help screen shows the version and the build identifier |
| Slide commands in the palette | Add, duplicate, delete, merge, split, AI layout and summarize can be run from the command palette |

### 2.2 Bug fixes

**Data safety**

- An AI result could be applied to a different document than the one it was requested for, or to a paragraph that had been edited after the request was sent. A result is now applied only when the tab, the loaded document and the text that was sent all still match (BUG-001).
- The inline completion (ghost text) could query the AI as soon as a file was opened, and pressing Tab could insert it into the text. It now queries only after you type, and Tab accepts only a suggestion that was made for the current text (BUG-001).
- Switching between Markdown, Editor and Slides marked the document as unsaved and rewrote the Markdown source. Switching now changes only the view. A round trip without edits leaves the source byte-for-byte identical (BUG-019).
- An unclosed code block swallowed every paragraph after it.
- Code blocks fenced with `~~~` were not recognized.
- Opening a Markdown file with CRLF line endings marked it as unsaved.
- Saving marked whichever tab was in front when the write finished as saved. It now marks only the tab that was written.

**Editing and Undo**

- After selecting text in a paragraph and replacing it, Undo went back to an empty paragraph instead of the text before the replacement (BUG-002).
- ⌘Z right after a replace undid the find field, not the document.
- ⌘Z in the title field or in a dialog field undid the whole document. It now undoes that field.
- The unsaved indicator stayed on after Undo returned the document to its saved content (BUG-015).

**Slides and export**

- Speaker notes could not be entered on the first slide when it is made from the document title (BUG-007).
- Slide bodies showed bold, links, bullet lists and code blocks as raw symbols. They are now shown as formatting in Preview, Presentation mode and PPTX (BUG-020).
- PPTX export left out images stored in the same folder as the document (G11).
- **Export as PDF** told the user to use a print dialog that never opened (BUG-003).
- Exports could be written to a path with no extension, which made it possible to overwrite configuration files.

**AI and models**

- When a draft failed, an empty tab was left behind and the entered text was lost. The dialog now stays open on failure and keeps the input so you can retry (BUG-014).
- Running **Analyze** on an empty document marked it as analyzed and unsaved (BUG-015).
- A free model that is no longer offered was among the default choices. The error for an unavailable model was also an English message that did not name the model (BUG-013).
- Draft length in Japanese was specified in words, so the result did not match the request. It is now specified in characters, and the achieved length and the target are shown after drafting (BUG-005).
- Loading the OpenRouter list sent the API key based on an endpoint that had not been saved yet.

**Dialogs and keyboard**

- The Draft, Help and Settings dialogs could not be closed with Esc (BUG-016).
- With a dialog open, focus could move to a button behind it, and that button could be operated (BUG-017).
- ⇧⌘S overwrote the file instead of opening Save As (BUG-009).
- Shortcuts acted behind Presentation mode.

**Display and wording**

- Japanese length was labelled as words. A mostly Japanese document is now counted in characters (BUG-012).
- In Markdown source, the heading underline and the active-line fill overlapped and made Japanese text look covered (BUG-008).
- Japanese labels were changed: 「Markdown編集」 is now 「Markdown」, and 「ファイルを隠す」 is now 「ファイル一覧を非表示」. In English, the collapsed sidebar toggle now reads **Show files** (BUG-009).
- English text left in the Japanese UI (tooltips, notifications, input examples, Help text) was translated.
- "Unsaved" and "No changes since last save" were shown at the same time (BUG-015).

### 2.3 Behavior changes (things to know when updating)

| Change | Before | This version |
|---|---|---|
| ⇧⌘S | Overwrites the file | Save As |
| PDF export | Points to a print dialog (which never opened) | Writes directly from a save dialog. Images and diagrams are not included |
| Inline completion | Appears when the cursor rests at the end of a paragraph | Appears after you type and pause |
| Switching modes | Marks the document as unsaved | Does not mark it as unsaved. In exchange, the last viewed mode is recorded in the file only when it is saved together with another change |
| Last tab | Cannot be closed | Closing it leaves a new empty document |
| ⌘K (command palette) | Always opens | Does not open on top of another dialog |
| Name of the per-paragraph AI button | "AI actions" (「AI操作」) | "Rewrite, translate or illustrate with AI…" (「AIで書き換え・翻訳・図解…」). Automation scripts that find the element by this name need updating |
| Draft length in Japanese | About 300 words (語), and so on | About 600 characters (文字), and so on (one word counted as about two characters). English labels still use words |
| OpenRouter model list | — | Load it after saving the endpoint and the API key |
| Export destination with no extension | Allowed | Refused |

### 2.4 Earlier changes that are in a version for the first time

These features were built after v1.3.0 and were already in the build that QA tested. This is the first time they ship under a version number. See v1.4.0 in `CHANGELOG.md` for details.

- The app was renamed to NurumayuEditor (settings, saved API keys and the `.aix` format keep working unchanged)
- Markdown workspace (Edit, Preview and Split layouts, editing directly in the preview, opening and saving `.md` files directly, a folder browser)
- Speaker notes, Presentation mode, and the view of changes since the last save
- Inline completion (ghost text)
- Per-paragraph character-limit warnings, and checking against review criteria
- Personal library (RAG over your own documents, processed on the device)
- Citation management (BibTeX import, APA and IEEE styles, lookup by DOI or arXiv id)
- Running AI actions from the command line, and an MCP server (read-only)
- A count of external network calls
