## 1. このアップデートの概要

- QA 実行 `20260927-computer-use-v1` で報告された不具合 21 件のうち 18 件を修正した。データが意図せず書き換わる不具合（AI の結果が別の文書に入る、モード切り替えで Markdown が書き換わる）を含む。
- 新機能として、検索と置換、OpenRouter のモデル一覧からのモデル選択、PDF の直接書き出しを追加した。
- 日本語 UI に残っていた英語表記を翻訳した。
- v1.3.0 の後に作られ、バージョン番号を付けて出していなかった機能（Markdown ワークスペースなど）も、このバージョンに含まれる（2.4 節）。
- **実機での動作確認はまだ行っていない。** 自動テストはすべて成功している（5 章）。分かっている問題は 3 章（Known Issues）、未実装の機能は 4 章（Future Release）にすべて記載した。

## 2. アップデート内容

### 2.1 新機能

| 機能 | 内容 |
|---|---|
| 検索と置換 | エディタと Markdown ソースで、検索・置換・次を検索・前を検索・行へ移動が使える。編集メニュー、⌘F / ⌥⌘F / ⌘G / ⇧⌘G / ⌘L、コマンドパレットから呼び出せる。「すべて置換」は 1 回の Undo で戻せる。日本語の検索に対応 |
| OpenRouter のモデル一覧 | 設定画面で現在のモデル一覧を取得し、検索・無料のみの絞り込み・料金の確認をして、テキスト用と画像生成用のモデルを選べる。一覧にない保存済みモデルには印が付く |
| PDF の直接書き出し | 「PDF として書き出し」が保存ダイアログを開き、ファイルを直接書き出す。入らなかった画像や図の件数をステータスバーに表示する |
| 別名で保存の入口 | 保存ボタンのメニューとコマンドパレットに「別名で保存…」を追加した。⇧⌘S で開く |
| 未保存時の 3 択 | タブを閉じるときと終了するときに「保存 / 保存しない / キャンセル」を選べる |
| 最後のタブを閉じる | 最後の 1 つのタブも閉じられる。閉じると新しい空の文書になる。ファイルメニューに「タブを閉じる」を追加した |
| 最近の AI 操作ログ | ネットワークパネルに、AI 操作の開始・反映・破棄と破棄の理由を表示する。記録するのは識別子だけで、本文や API キーは含まない。コピーできる |
| ビルド識別子の表示 | ヘルプ画面の下部にバージョンとビルド識別子を表示する |
| スライド操作のパレット登録 | スライドの追加・複製・削除・結合・分割・AI レイアウト・要約を、コマンドパレットから実行できる |

### 2.2 不具合の修正

**データの安全性**

- AI の結果が、依頼したものとは別の文書や、送信後に書き換えた段落に反映されることがあった。依頼を出したタブ、その時に読み込んだ文書、送信時の本文と一致する場合だけ反映するようにした（BUG-001）。
- 行末の補完候補（ゴーストテキスト）が、ファイルを開いただけで AI に問い合わせ、Tab キーで本文に入ってしまうことがあった。文字を入力した後にだけ問い合わせ、現在の本文に対して作られた候補だけを確定するようにした（BUG-001）。
- Markdown・エディタ・スライドを切り替えるだけで文書が未保存になり、Markdown のソースが書き換わっていた。切り替えは表示だけを変えるようにした。編集せずに往復した場合、ソースは 1 バイトも変わらない（BUG-019）。
- 閉じていないコードブロックが、それ以降の段落を飲み込んでいた。
- `~~~` で囲んだコードブロックを認識していなかった。
- CRLF 改行の Markdown を開くだけで未保存になっていた。
- 保存処理が、書き込みが終わった時点で前面にあるタブを保存済みにしていた。書き込んだタブだけを保存済みにするようにした。

**編集と Undo**

- 同じ段落で文字を選択して置き換えたあとの Undo が、置き換え前ではなく空の状態まで戻っていた（BUG-002）。
- 置換の直後の ⌘Z が、文書ではなく検索欄を戻していた。
- タイトル欄やダイアログの入力欄で ⌘Z を押すと、文書全体が戻っていた。その入力欄の Undo が働くようにした。
- Undo で保存時の内容に戻っても、未保存の表示が残っていた（BUG-015）。

**スライドと書き出し**

- 文書タイトルから作られる 1 枚目のスライドで、発表者ノートを入力できなかった（BUG-007）。
- スライド本文で、太字・リンク・箇条書き・コードブロックが記号のまま表示されていた。プレビュー、発表モード、PPTX のすべてで書式として表示するようにした（BUG-020）。
- PPTX 書き出しで、文書と同じフォルダにある画像が入らなかった（G11）。
- 「PDF として書き出し」が、開かない印刷ダイアログを案内していた（BUG-003）。
- 拡張子のないパスへ書き出せてしまい、設定ファイルなどを上書きできる状態だった。

**AI・モデル**

- 下書きの生成に失敗すると、空のタブが残り、入力した内容が消えていた。失敗時はダイアログを開いたままにし、入力を残して再試行できるようにした（BUG-014）。
- 空の文書で「関係を分析」を実行すると、分析済み・未保存になっていた（BUG-015）。
- 提供が終了した無料モデルが既定の候補に入っていた。モデルが使えないときのエラーも、モデル名を示さない英語のメッセージだった（BUG-013）。
- 日本語の下書きの長さを「語」で指定していたため、指定と結果が合わなかった。「文字」で指定し、生成後に実績と目標を表示するようにした（BUG-005）。
- OpenRouter の一覧取得で、保存する前のエンドポイントを基準に API キーを送っていた。

**ダイアログとキーボード**

- 下書き・ヘルプ・設定のダイアログを Esc で閉じられなかった（BUG-016）。
- ダイアログを開いたまま、背面のボタンにフォーカスが移り、操作できた（BUG-017）。
- ⇧⌘S が「別名で保存」ではなく上書き保存になっていた（BUG-009）。
- 発表モードの裏でショートカットが働いていた。

**表示と文言**

- 日本語の文字数が「語」と表示されていた。日本語主体の文書は「文字」で数える（BUG-012）。
- Markdown ソースで、見出しの下線と選択行の塗りが重なり、日本語の文字が隠れて見えていた（BUG-008）。
- 「Markdown編集」を「Markdown」に、「ファイルを隠す」を「ファイル一覧を非表示」に変更した（BUG-009）。
- 日本語 UI に残っていた英語表記（ツールチップ、通知、入力欄の例、ヘルプ本文）を翻訳した。
- 「未保存」と「前回保存から変更なし」が同時に表示されていた（BUG-015）。

### 2.3 動作の変更（アップデート時の注意）

| 変更 | 以前 | このバージョン |
|---|---|---|
| ⇧⌘S | 上書き保存 | 別名で保存 |
| PDF 書き出し | 印刷ダイアログの案内（実際には開かない） | 保存ダイアログから直接書き出す。画像と図は入らない |
| 補完候補 | 段落末尾にカーソルを置くと表示 | 文字を入力して手を止めると表示 |
| モード切り替え | 文書が未保存になる | 未保存にならない。その代わり、最後に見ていたモードは、ほかの変更と一緒に保存したときだけファイルに記録される |
| 最後のタブ | 閉じられない | 閉じると新しい空の文書になる |
| ⌘K（コマンドパレット） | いつでも開く | ほかのダイアログの上では開かない |
| 段落ごとの AI ボタンの名前 | 「AI操作」 | 「AIで書き換え・翻訳・図解…」。この名前で要素を探す自動化スクリプトは更新が必要 |
| 日本語の下書きの長さ | 約 300 語 など | 約 600 文字 など（1 語を約 2 文字として換算） |
| OpenRouter のモデル一覧 | — | エンドポイントと API キーを保存してから取得する |
| 拡張子のない書き出し先 | 書き出せる | 拒否する |

### 2.4 以前からの変更で、このバージョンに初めて含まれるもの

v1.3.0 の後に作られ、今回の QA の対象ビルドにはすでに入っていた機能である。バージョン番号を付けて出すのは今回が初めてになる。詳細は `CHANGELOG.md` の v1.4.0 を参照。

- アプリ名を NurumayuEditor に変更（設定・保存済みの API キー・`.aix` 形式はそのまま使える）
- Markdown ワークスペース（編集・プレビュー・分割表示、プレビュー上での直接編集、`.md` を直接開いて保存、フォルダの一覧表示）
- 発表者ノート、発表モード、前回保存からの変更の表示
- 行末の補完候補（ゴーストテキスト）
- 段落ごとの文字数上限の警告、審査基準との照合
- 個人ライブラリ（手元の資料を使った RAG。端末内で処理）
- 文献管理（BibTeX の取り込み、APA・IEEE 形式、DOI・arXiv からの取得）
- コマンドラインからの AI 実行、MCP サーバー（読み取り専用）
- 外部通信の回数の表示
